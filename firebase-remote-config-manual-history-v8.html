如何获取 Firebase Web App 配置

只需在每个 Firebase Project 注册一次 Web App。无需部署网站，也无需修改已有 Android App。

  1. 打开 Firebase 控制台，登录对应的 Google 账号，并选择需要验证的 Firebase Project。
  2. 点击左上角项目名称旁的 齿轮图标 ⚙ → 项目设置（Project settings）。
  3. 进入 常规（General）→ 您的应用（Your apps）。
  4. 如果还没有 Web App，点击 Web 图标（</>） 添加应用。填写一个容易识别的昵称，例如 Remote Config Verifier，点击 注册应用（Register app）。不需要勾选 Firebase Hosting。
  5. 如果已经有 Web App，在「您的应用」列表中直接选择该 Web App。
  6. 找到 SDK 设置和配置（SDK setup and configuration），选择 配置（Config），复制显示的整个 firebaseConfig 代码块。也可以复制 npm 选项中包含 const firebaseConfig = { ... } 的整段代码。
  7. 返回本工具，将复制内容完整粘贴到左侧输入框，点击 解析并保存，再点击 初始化 和 手动获取最新配置并记录。
注意：必须使用 Web App 的配置，appId 中应包含 :web:，不能直接粘贴 Android 的 google-services.json。如果 Remote Config 参数没有条件值，Web App 获取到的默认值可用于核对该 Project 的默认配置下发；但不能代替 Android 客户端的实际拉取测试。
